# 内置项目管理技能(pm-skills-zh)

来源:<https://github.com/killvxk/pm-skills-zh>(Pawel Huryn 的 PM skills 中文版,MIT 许可,原文见同目录 LICENSE)。

- 每个技能一个目录,身份就是目录名(与应用的技能约定一致);
- 这些技能**只在协作群组里可选**(成员编辑器的「项目管理(内置)」分组),
  不进设计会话的自动加载,也不出现在纯聊天的技能选择器;
- 用户想覆盖某个同名技能,把自己的版本放进 ~/.antd-designer/skills 等
  更高优先级目录即可,不用改这里;
- 更新方式:从上游仓库重新拷贝各 `pm-*/skills/*` 目录的 SKILL.md。
