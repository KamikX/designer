# 排版手艺

这些规则与品牌无关。任何设计体系之上都适用。

## 字距:最常被跳过、也最能暴露业余的一条

| 场景 | letter-spacing |
| --- | --- |
| 正文 14–18px | `0`(默认) |
| 小字 11–13px | `0.01em` ~ `0.02em`(**正值**) |
| 界面标签、按钮文字 | `0.02em` |
| **全大写** | **`0.06em` ~ `0.1em`(必须)** |
| 标题 32px+ | `-0.01em` ~ `-0.02em` |
| 展示级 48px+ | `-0.02em` ~ `-0.03em` |

**全大写不加正字距会挤成一团;大字号不加负字距会松垮无力。这两条是 AI 产出最可靠的破绽。**

`0.06em` 这个下限不是拍脑袋:西文排印传统对大写字母的字距建议是字身的 5–10%,
屏幕实践取下限约 0.06em。再紧字腔就粘连,超过 0.1em 单词会散成字母。

中文没有大写概念,但同理:**中文标题要收紧**(`-0.02em` 左右),
中英混排时英文部分单独给字距,否则英文看着比中文松。

## 三档字重,不要阶梯

```
读   400 / 450   正文
强调 510 / 550   界面文字、标签、导航
宣告 590 / 600   标题、按钮
```

700 以上几乎用不到。如果你在用粗体做"强调之上的强调",说明别处的字重纪律出了问题。

**反模式:阶梯式字重** —— regular → medium → semibold → bold → extrabold 一级一级往上加。
那读起来像默认刻度,不像有人设计过。**字重应该跳,不应该爬。**

## 字体搭配

- 一份产物**最多两种字体**
- 标题字体 ≠ 正文字体。只有数据密集的工具类界面可以只用一种
- 必须写完整的系统回退链
- **绝不要在标题上单独写 `font-family: system-ui`** —— 那是教科书级的 AI 默认值。
  要用也得配一个明确的首选字体在前面

## 行高与行长

| 用途 | line-height | 行长 |
| --- | --- | --- |
| 展示级标题 | 1.02 ~ 1.1 | — |
| 小标题 | 1.2 ~ 1.3 | — |
| 正文 | 1.5 ~ 1.65 | **45–75 字符** |
| 密集界面 | 1.4 | — |

正文超过 75 字符宽,眼睛回扫时会跳行。用 `max-width: 60ch` 而不是像素值。

## 自查

- [ ] 全大写的地方都有 ≥ `0.06em` 字距
- [ ] 32px 以上的字都有负字距
- [ ] 首屏可见的字号不超过 3 种
- [ ] 正文不是 `text-align: justify`(会产生"河流",web 上永远不要用)
- [ ] 标题和正文是两种不同的字体(数据密集型界面除外)
