# 排版手艺

先读 StyleBrief。以下是 StyleBrief 没有给出排印方向时的可读性建议，不是覆盖项目字体
体系、字距或层级选择的硬规则；明确的品牌或产品要求优先。

## 字距:最常被跳过、也最能暴露业余的一条

| 场景               | letter-spacing                   |
| ------------------ | -------------------------------- |
| 正文 14–18px       | `0`(默认)                        |
| 小字 11–13px       | `0.01em` ~ `0.02em`(**正值**)    |
| 界面标签、按钮文字 | `0.02em`                         |
| **全大写**         | **`0.06em` ~ `0.1em`(常用起点)** |
| 标题 32px+         | `-0.01em` ~ `-0.02em`            |
| 展示级 48px+       | `-0.02em` ~ `-0.03em`            |

全大写若没有足够字距容易粘连；大字号可通过较紧字距获得更凝聚的节奏。是否采用、采用多少，
仍以 StyleBrief 的字体与语言要求为准。

`0.06em` 这个下限不是拍脑袋:西文排印传统对大写字母的字距建议是字身的 5–10%,
屏幕实践取下限约 0.06em。再紧字腔就粘连,超过 0.1em 单词会散成字母。

中文没有大写概念；中文标题可按字形和品牌气质微调字距。中英混排时，单独检查英文部分的
字距是否与中文协调。

## 字重层级示例

```
读   400 / 450   正文
强调 510 / 550   界面文字、标签、导航
宣告 590 / 600   标题、按钮
```

较重字重会放大视觉强调；是否使用取决于字族可用字重、StyleBrief 和内容层级。

连续细分字重有时会弱化层级；若界面读起来发平，可尝试拉开关键层级的重量差。

## 字体搭配

- 标题、正文、数据或代码可使用同一字体体系，也可分工使用不同字体；选择应服务
  StyleBrief、语言覆盖和信息层级，而不是追求某种固定搭配。
- 为实际运行环境准备可靠的回退链，并验证目标语言的字形、数字和符号可读性。
- 若使用系统字体，应让它与 StyleBrief 的气质和层级策略一致；不因字体类别本身判定好坏。

## 行高与行长

| 用途       | line-height | 行长           |
| ---------- | ----------- | -------------- |
| 展示级标题 | 1.02 ~ 1.1  | —              |
| 小标题     | 1.2 ~ 1.3   | —              |
| 正文       | 1.5 ~ 1.65  | **45–75 字符** |
| 密集界面   | 1.4         | —              |

正文超过 75 字符宽,眼睛回扫时会跳行。用 `max-width: 60ch` 而不是像素值。

## 自查

- [ ] 全大写和大字号的字距经过目标语言与可读性检查
- [ ] 首屏的字号数量与 StyleBrief 的层级策略一致
- [ ] 正文对齐方式没有制造影响阅读的异常空隙
- [ ] 标题、正文和数据的字体选择与 StyleBrief、语言覆盖及信息层级一致
