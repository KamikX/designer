# PC Web 应用

Web 应用和落地页的根本区别:落地页给人**看**,应用给人**用**。装饰性的东西
(大首屏、渐变、宣传文案)在这里都是噪音;hover、焦点、键盘、快捷键才是一等公民。

## 开工前:判读与提问

判读一句话:「核心对象是〈什么〉,用户主要在〈哪种工作区〉里〈做什么〉。」
缺关键信息才问,最多一次,不超过 3 题:

1. **核心对象**:文档 / 任务 / 媒体 / 数据记录 / 会话
2. **工作区形态**:列表+详情双栏(默认) / 三栏(导航+列表+详情) / 画布 / 编辑器
3. **信息密度**:舒适(默认) / 紧凑(专业用户整天用的工具选这个)

信号追问:

| 用户提到   | 追问                                                |
| ---------- | --------------------------------------------------- |
| 协作、团队 | 要不要体现在线状态/头像?多人编辑冲突怎么提示        |
| 搜索       | 全局搜索(⌘K 风格)还是列表内筛选?                    |
| 拖拽、排序 | 拖拽中的视觉反馈与放置指示怎么做,占位符要不要       |
| 大量数据   | 上万条走虚拟滚动语义:固定行高 + 分页/无限加载二选一 |

## 布局路由

| brief 里出现             | 用                                              |
| ------------------------ | ----------------------------------------------- |
| 收件箱、任务、工单、客服 | 双栏:左列表(320px) + 右详情,列表项有已读/选中态 |
| 文档、笔记、知识库       | 三栏:侧导航(240px) + 目录树 + 编辑区(66ch 行长) |
| 看板、项目               | 顶栏 + 水平滚动列,卡片可拖拽                    |
| 画布、设计、流程图       | 全屏画布 + 浮动工具条 + 可收起属性面板          |
| 会话、聊天、AI           | 侧栏会话列表 + 主区消息流 + 底部输入框          |

## 风格维度:每一项都要做选择,别每次都默认同一组

工作区形态管结构,这里管气质。**用户给了方向听用户的**;没给就按 brief 选,
判读时逐项声明,**连续两个项目不许选同一组**:

| 维度       | 选项                                                  |
| ---------- | ----------------------------------------------------- |
| 侧栏风格   | 浅色描边(默认) / 深色沉底 / 无侧栏顶部导航            |
| 密度       | 舒适 / 紧凑(专业用户整天用)                           |
| 卡片风格   | 描边卡片 / 无边框平铺+分割线                          |
| 明暗       | 浅色 / 深色 / 跟随内容气质                            |
| 品牌色注入 | 当前项+主按钮(默认) / 深色侧栏整条品牌色调 / 顶栏细条 |

品牌色按 StyleBrief 生成，并与 design-seed 的语义 token 保持一致。

## 硬规则

- **每个可点元素都有 hover 与 focus-visible 态**,颜色或背景变化,不许没有。
- 键盘可用:Tab 顺序合理,列表支持 ↑↓ 移动选中;做全局搜索就配 ⌘K。
- 侧栏导航当前项要有明确指示(背景块或左侧 2px 竖条,选一种,别都要)。
- 主操作一屏一个 `bg-brand-500` 按钮;其余动作一律次级(描边或幽灵)。
- 行内操作(编辑/删除)hover 才浮现,但**触屏兜底**:不要让功能只藏在 hover 里。
- 空态、加载骨架、错误重试三态齐全;表格与列表的数字 `.num` 等宽右对齐。
- 不做大 hero、不写宣传语。应用的第一屏就是干活的界面。

## 交付前自查

- [ ] 拔掉鼠标走一遍:纯键盘能到达并触发每个主要操作吗?
- [ ] 数一遍主按钮:一屏之内 `bg-brand-500` 是不是只有一个?
- [ ] 新用户第一次打开(零数据)看到的是引导性空态,还是一片惨白?
- [ ] 界面上有没有一句话是"说给访客听的"?有就删——用户已经在用了,不需要被推销
