# 落地页

一个落地页只做一件事:让一类明确的人,做一个明确的动作。写第一行代码之前,
这两个空必须填上——填不上就先问(见下)。

## 开工前:判读与提问

先用一句话输出你的判读:「这页给〈谁〉看,让他〈做什么〉,气质偏〈哪种〉。」
判读里有空填不上、且 brief 里确实没有,才问;**最多问一次**,用 ask_user,
一次不超过 3 题,每题给选项:

1. **主行动**:注册试用 / 下载 / 预约演示 / 加入等待名单 / 联系销售
2. **受众**:开发者 / 企业决策者 / 普通消费者 / 内部同事
3. **气质**:可信专业(默认) / 技术极客 / 温和消费 / 编辑杂志感

用户话里带了信号就追对应的问,别问通用问卷:

| 用户提到 | 追问 |
| --- | --- |
| 定价、付费 | 几个档位?有没有年付折扣?(这决定要不要对比表) |
| 数据、成绩 | 有真实数字吗?没有就用诚实占位,**不编** |
| 竞品、对比 | 允许点名吗?不允许就做"有/无我们"的对比,不出现对方名字 |
| 多语言、出海 | 主语言是哪种?中英文排版规则不同 |

## 页面节奏:查表,不即兴

先激活 design-seed(种子 token + 版面库都在那边),再按类型挑节奏:

| 类型 | 节奏 |
| --- | --- |
| 产品官网 | 左对齐首屏 → 三栏特性 → 数据条**或**引言 → 自定义分栏 → 行动号召 |
| 等待名单 | 居中首屏(表单就在首屏) → 三栏特性 → 引言 |
| 定价页 | 居中首屏 → 对比表 → FAQ → 行动号召 |
| 活动/发布 | 居中首屏(带日期) → 日程/内容列表 → 行动号召 |

## 风格维度:每一项都要做选择,别每次都默认同一组

节奏表管结构,这里管气质。**用户给了方向听用户的**;没给就按 brief 选,
判读时逐项声明(「气质〈编辑杂志〉,首屏〈左对齐+大字〉,字体〈衬线标题〉,
背景〈分区色块〉,圆角〈小〉」),**连续两个项目不许选同一组**:

| 维度 | 选项 |
| --- | --- |
| 版式气质 | 可信专业 / 技术极客(等宽点缀、密网格) / 编辑杂志(衬线标题、大留白) / 温和消费(圆角、暖色) / 极简留白 |
| 首屏形态 | 左对齐大字(默认) / 居中单主张 / 左文右视觉分栏 / 全宽产品截图压轴 |
| 标题字体 | 无衬线全家 / 衬线标题+无衬线正文 / 等宽标题(仅技术产品) |
| 背景处理 | 通页纯色 / 分区色块(相邻区块换底色) / 首屏深色其余浅色 |
| 圆角档 | 锐利(2-4px) / 适中(8px) / 圆润(12px+) |

品牌色按 design-seed 的规则定(用户方向优先,占位色必换)。

## 硬规则

- 主 CTA 全页**一种措辞、一种样式**;首屏一个,页尾一个,中间最多再出现一次。
- 相邻区块不得同版式;整页版式家族 ≥3 种。左右分栏连排最多 2 次。
- `eyebrow` 小标签总数 ≤ 区块数的一半;每个都必须有信息量,"关于我们"这种废话不配。
- 首屏 h1 ≤16 个汉字(英文 ≤9 词),说用户得到什么,不说"我们是谁"。
- 社会证明只用拿得出手的:有真 logo/真数据就放,没有就整段删掉,**不摆灰色假 logo 墙**。
- 文案全部具体到这一个产品。写完通读一遍:任何一句换个产品名也成立的话,重写。

## 交付前自查(全过才算完成)

- [ ] 数一遍 CTA:主行动是不是只有一种措辞?
- [ ] 数一遍版式:有没有连续 3 个区块长得一样?
- [ ] 搜一遍数字:每个数字要么有出处,要么是 `—` 占位。有一个编的都不行
- [ ] 把首屏截给项目外的人看:能看出这是**什么产品**吗?看不出就是模板,重写首屏文案
