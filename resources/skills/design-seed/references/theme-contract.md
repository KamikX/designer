# theme.css 语义 token 契约

这是一份接口契约，不是视觉方案。创建项目的 `theme.css` 时才按需读取；具体值由
StyleBrief、已确认的兜底方向和产品内容决定。

## 必须覆盖的语义类别

| 类别       | token 接口                                                                               | 映射要求                                                                             |
| ---------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 画布与表面 | `--color-bg`、`--color-surface`、`--color-raised`、`--color-sunken`                      | 页面底、容器、浮层和凹陷区域各有明确层级，明暗与色温来自 StyleBrief。                |
| 文字与边界 | `--color-ink`、`--color-ink-muted`、`--color-line`、`--color-line-strong`                | 正文、辅助信息、分隔和聚焦边界保持可辨性；不要用装饰色代替信息层级。                 |
| 品牌与交互 | `--color-brand-500`、`--color-brand-600`、`--color-focus`                                | 主动作、链接、悬停和键盘焦点属于同一品牌语义，焦点状态必须可见。                     |
| 状态       | `--color-success`、`--color-warning`、`--color-danger`、`--color-info`                   | 状态色只表达状态，不和品牌色混用；文字、图标与非色彩提示共同传达含义。               |
| 字体与排印 | `--font-display`、`--font-body`、`--font-mono`、`--text-*`、`--leading-*`                | 标题、正文、数据和代码各自映射到用途；字体体系、字号阶梯与行高由 StyleBrief 决定。   |
| 间距与容器 | `--space-*`、`--spacing-section`、`--spacing-block`、`--spacing-gutter`、`--container-*` | 页面节奏、组件内距和数据密度共享同一套尺度，不把某个页面的尺度硬编码成通用规则。     |
| 几何与表面 | `--radius-*`、`--border-*`、`--shadow-*`、`--color-overlay`                              | 圆角、边框、阴影、玻璃感或平面感要表达同一几何语言，不能覆盖 StyleBrief 的表面选择。 |
| 动效       | `--duration-*`、`--ease-*`                                                               | 悬停、展开、加载和减少动态偏好使用一致的节奏；遵守 `prefers-reduced-motion`。        |

## 组件映射

- `body`、页面区块和布局容器只能消费画布、文字、间距与排印 token。
- 按钮、链接、输入框和焦点环消费品牌、状态、几何与动效 token，并提供默认、悬停、
  聚焦、禁用、加载和错误状态。
- 卡片、弹层、表格和导航消费表面、边界、间距与几何 token；不同层级必须可区分。
- 数据表、表单和状态反馈应同时提供颜色以外的文字、图标、轮廓或布局线索。
- 使用 antdv-next 时，将 `colorPrimary`、字体、圆角、明暗基调及必要的组件 token 映射
  回同一份 `theme.css` 语义，而不是另造一套视觉语言。

## 质量下限

- 文字与背景、边界与相邻表面、焦点环与周围内容都要有足够对比度。
- 语义 token 的名称表达用途，不以某个项目的颜色、字体或像素值命名。
- 允许项目新增 token；新增项也必须能说明它服务的语义和状态。
