# 设计种子

## 第 0 步:先读,再写

1. **完整读一遍 `assets/theme.css`**。它已经把配色、排版、字距、阴影梯度都调好了
2. **读 `references/layouts.md`**,知道有哪些现成的区块骨架
3. 复制 `assets/theme.css` 成项目的 `theme.css`,**只改 `@theme` 里那几个值**

**不要从零写 CSS。** 这是产出退回"通用 AI 观感"的头号原因——每次重新推导一遍
好的默认值,而每次都只能推导出平均水平。种子里那些字距、行高、阴影的取值不是
随便填的,重写一遍必然丢掉。

## 只改这几个

| 改 | 不改 |
| --- | --- |
| `--color-brand-500/600`(**必改**,见下) | 字距、行高 |
| `--color-bg` 系列的色温 | 阴影梯度 |
| `--font-display` | `.eyebrow` 的 0.08em |
| `--radius-base` | `.card` 静止时不带阴影 |

## 品牌色:占位必换,来源按这个优先级

种子里的 `#c96442` 是**占位符,不是调好的默认**——原样交付会被反 AI 味检查记为
退步(所有项目长一个样,和满屏 Tailwind 靛蓝是同一种病)。按优先级定色:

1. **用户给了方向就听用户的**:说了具体颜色照用;说了气质("科技感""温暖一点"
   "像 Stripe 那样")就往那个方向调。吃不准时问一句,别猜。
2. **brief 能推断就推断**:行业与受众自带色彩语言(金融偏稳、儿童偏暖、
   开发者工具偏冷)。
3. **都没有,从下表选一族**,同一场景连续两个项目**不要选同一族**:

| 家族 | brand-500 | brand-600 | 适合 |
| --- | --- | --- | --- |
| 石墨极简 | `#3d3d3f` | `#2a2a2c` | 工具、开发者产品、极简品牌 |
| 靛青科技 | `#4c5fd5` | `#3f4fb8` | SaaS、数据产品(注意别滑向 Tailwind 靛蓝 #6366f1) |
| 森绿 | `#2f7d5c` | `#276a4e` | 健康、财务、可持续 |
| 绛红 | `#b23a48` | `#9a2f3c` | 内容、餐饮、票务 |
| 青碧 | `#0f7b8a` | `#0c6875` | 医疗、教育、企业服务 |
| 琥珀 | `#b07d2e` | `#996b25` | 生活方式、电商、创作者 |
| 暖橙 | `#c96442` | `#b45a3b` | 社区、本地服务(= 种子占位色系,选它也要微调色值) |

选定后在动手前的判读里**说出来**:「品牌色取〈来源:用户指定/brief 推断/某族〉,
背景色温〈暖/冷/中性〉」——让用户在你写 CSS 之前就能便宜地改方向。
中性色温跟着品牌走:冷色 brand 配冷灰,暖色 brand 配暖灰,别一律套种子的暖底。

## 第一个页面画设计体系本身

token 定完之后,**先画一个可预览的规范页**(html 栈叫 `design-system.html`,
vue3/react 就是一个可切换的视图),而不是直接做业务页。

用户要能**看见**你定了什么,而不是去代码里翻 CSS 变量。这一页包含:

- 色板:每组一行,色块 + token 名 + 色值
- 字号阶梯:每级用真实文案示范
- 圆角与阴影:各档位摆出实物方块
- 基础组件:按钮(主/次 × 默认/悬停/禁用)、输入框、卡片、标签、空态

这一页同时是给用户的"设计交底",也是你后续所有页面的取样板。

## 页面节奏:查表,不要即兴

| 页面类型 | 默认节奏 |
| --- | --- |
| 落地页 | 首屏 → 三栏特性 → 数据条 **或** 引言 → 自定义分栏 → 行动号召 |
| 内容/编辑向 | 居中首屏 → 日志列表 → 行动号召 |
| 定价 | 居中首屏 → 对比表 → 行动号召 |
| 中后台 | 顶栏 → 筛选区 → 表格 → 分页 |

**动手前先用一句话说出你选的节奏**,让用户此刻就能便宜地改方向,
而不是等你写完两百行 HTML。

## 收尾:五维自评

写完之后按 1–5 分默默给自己打分:

1. **气质** —— 视觉姿态是否符合要求?还是又退回了你最顺手的那套默认?
2. **层级** —— 一屏之内视线是否有一个明确的落点?
3. **执行** —— 排版、间距、对齐、对比是"对"还是只是"接近"?
4. **具体性** —— 每个字、每个数、每张图是否只属于**这一份**需求?
5. **克制** —— 强调色最多两处、一个决定性的亮点,还是三个在互相抢?

**任何一维低于 3 分都算退步。回去改最弱的那一维,重新打分。两轮是正常的。**
